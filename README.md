# Tantu Wholesale Studio

A Next.js storefront concept for a retailer-first Indian clothing wholesale business.

## Run locally

1. Install Node.js (LTS).
2. From this folder, install dependencies with `npm install`.
3. Start the development server with `npm run dev`.
4. Open http://localhost:3000.

## Before using as a live store

- Replace the Tantu Wholesale Studio concept name and visual identity with the business's approved brand.
- Add verified product records, pack quantities, prices and price basis, inventory, dispatch timing, and policies.
- Connect the inquiry form to an approved sales inbox or CRM. The current form is a frontend preview and does not transmit submissions.
- Replace the example.com metadata base with the production domain using NEXT_PUBLIC_SITE_URL.
- Update robots/indexing metadata only after the real business content and domain are ready.
- Confirm rights to all product photos and brand assets. The hero image is original generated editorial artwork and is not a real product listing.
- Add privacy, shipping, returns, payment, and contact pages before accepting customer data or orders.

## SEO notes

The page includes a retailer-focused title/description, semantic sections, and category copy. Search visibility depends on real category/product content, crawlable URLs, accurate inventory and offer data, a production domain, sitemap, canonical rules, and Search Console setup. The preview is configured as noindex until the business details are confirmed.
